# Study Quest

A small interactive learning game built with React. Players answer generated math problems, short reading questions, and missing-word questions. Correct answers earn points and streak bonuses; three incorrect answers end the quest.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The output in `dist/` can be deployed to any static host such as Netlify or Vercel.

## How to play

Choose Math Lab, Story Corner, Word Workshop, or a mixed quest. Answer up to ten questions, build a streak for bonus points, and review your result at the end. The game ends early after three incorrect answers. Questions and score stay in the browser session; no account or backend is required.
