# Study Quest

A small interactive learning game built with React. Players type answers to generated math problems, decide yes or no after reading short stories, and place words into sentences. A ten-step map tracks progress. Their customizable companion earns XP and subject skills across sessions, levels up, and gains a crown at level 3. Correct answers earn points and streak bonuses; players have three hearts and two hints.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The output in `dist/` can be deployed to any static host such as Netlify or Vercel.

## How to play

Choose Math Lab, Story Corner, Word Workshop, or a mixed quest. Challenges alternate between multiple choice and hands-on play. On hands-on turns, type math answers, place a word in a sentence, or choose Yes or No and check a reading answer. Build a streak for bonus points, use up to two hints, and review your result at the end. The game ends early after three incorrect answers. The companion's XP, level, skills, name, and color are saved in the browser; no account or backend is required.
